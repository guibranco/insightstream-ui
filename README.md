# ⚡ InsightStream

> **Streamlined Medium Newsletter Triage & Article Curator** 📬✨

InsightStream is a modern, high-efficiency web application designed to help tech readers and curators organize, prioritize, and triage articles extracted from daily email newsletter digests.

---

## 🌟 Key Features

- 📊 **Interactive Curator Dashboard**: View real-time status metrics, newsletter counts, and top-priority article recommendations.
- 🎯 **Smart Priority Scoring**: Automatically calculates article relevance scores on a 0–10 scale to highlight essential reads.
- 📥 **4-Stage Article Triage Flow**:
  - 📥 **Awaiting**: Freshly ingested articles pending review.
  - 💖 **Liked**: Saved favorite articles for deep reading or reference.
  - 👁️ **Reviewed**: Skimmed and marked as completed.
  - 🗑️ **Discarded**: Skipped articles kept out of your main queue.
- 🔍 **Search & Flexible Sorting**: Search by title, author, or domain, and sort by priority score, date, or title.
- 🎨 **Geometric Balance Theme**: Styled with an ultra-sleek dark canvas (`#0A0B0D`), deep plum accents (`#79378B`), and lime highlights (`#93CD3F`).
- 🌓 **Light & Dark Mode**: Seamlessly switch between themes or sync with system preferences.
- 📱 **Mobile & Desktop Support**: Responsive layout with desktop header navigation and mobile bottom tab bar.

## 🚀 Quick Start

### 📋 Prerequisites

- **Node.js** (v18 or higher recommended)
- **npm** or **yarn**

### 💻 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/insight-stream.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd insight-stream
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Start the development server**:
   ```bash
   npm run dev
   ```

5. **Open in browser**:
   Navigate to `http://localhost:3000` to interact with the application.

## 🛠️ Tech Stack

- ⚛️ **Frontend Framework**: React 18 with TypeScript & Vite
- 🎨 **Styling & UI**: Tailwind CSS & Lucide React Icons
- 📂 **Persistence & State**: Client-side LocalStorage Persistence & Async State Handlers

---

## ⚙️ App Preferences

Customizable settings in the **Preferences** panel (`/#/preferences`):
- 🎨 **Theme Options**: Light, Dark (Geometric Balance), or System Default
- 📐 **Display Mode**: Choose between Grid or List layout by default
- 📄 **Pagination**: Select articles per page (10, 20, or 50)
